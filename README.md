## Package Status

Pipeline: `READY-TO-UPLOAD/PUBLIC`

This package contains the final/published article scan for local reference plus the authored model/calculation artifacts found in the paper source folder. The paper is not an empirical-data paper. Its results are produced from a mathematical serial-network model evaluated with assumed coefficients; the reproducibility boundary is therefore the model derivation notebooks and spreadsheet calculation workbooks rather than raw observational data.

## Contents

- `paper/`: local reference copy of the published 30-page JTEP scan.
- `model_notebooks/`: Mathematica 3.0 derivation notebooks for the symbolic model expressions.
- `model_spreadsheets/original/`: original legacy Excel workbooks containing welfare, toll/tax, reaction-curve, and sensitivity calculations.
- `model_spreadsheets/modernized/`: LibreOffice `.xlsx` conversions of the legacy workbooks for easier modern inspection.
- `metadata/WORKBOOK_SHEET_INVENTORY.csv`: workbook sheet names, dimensions, formula-cell counts, and sample cells.
- `documentation/SOURCE_FILE_REVIEW.csv`: source-folder inclusion/exclusion decisions.
